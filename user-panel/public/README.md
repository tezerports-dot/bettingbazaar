# user-panel/public

<!-- GOVERNANCE: Read CLAUDE.md before editing this file. -->

Static files copied as-is into the web build (and therefore into the APK).

| Path | What it is |
|---|---|
| `app-assets/` | The default brand icons, GENERATED by `npm run icons:generate` (`scripts/generate-icons.mjs`). An admin upload on App Assets overrides them at runtime; these are the floor. |
| `manifest.json` | The PWA manifest. Its `theme_color` is the brand background the Android app mirrors (`nativeBrand.test.ts`). |
| `service-worker.js`, `config-init.js` | Web runtime; the SW is not registered inside the Android app. |

**No APK belongs here.** The Android app is built by the **Android release**
GitHub workflow and published from the admin panel's **Android App** page,
which stores it on the CDN; `/api/download/android` redirects to the newest
published release. See `docs/governance/ANDROID_RELEASE_SETUP.md`.
